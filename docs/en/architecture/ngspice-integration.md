# Reserved ngspice backend

[Tiếng Việt](../../vi/architecture/ngspice-integration.md) · [Backends](backends.md)

The reserved `ngspice` selector is `UNAVAILABLE` for analog and mixed-signal execution. It exposes zero channels and produces no samples. Qualification requires an exact executable and model library, reviewed licenses and integration evidence.

The earlier source and model input research is preserved in the [original Simulator repository](https://github.com/cirnetlab/cirnet-simulator/blob/7cdee6420a204f9b0cd2120ff9e65ee5ffd52b1c/docs/en/architecture/ngspice-integration.md).
