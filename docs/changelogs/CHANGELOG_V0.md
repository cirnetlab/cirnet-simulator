# 0.3.0-dev.1

## English

- Migrated the C++20 worker, bounded DC and CNP1/CNP2 regression tests.
- Added Windows x64 build, install and protocol verification.
- Recovered worker regressions for breadboard net fan-out, same-time input and probe order, and powered 74HC08 DC LED states.
- Linked the worker boundary to CIRNET Lab-First execution and acceptance requirements.

## Tiếng Việt

- Chuyển worker C++20 và kiểm thử hồi quy DC giới hạn, CNP1/CNP2.
- Thêm build, cài đặt và kiểm chứng giao thức trên Windows x64.
- Khôi phục kiểm thử hồi quy worker cho phân nhánh mạng breadboard, thứ tự đầu vào và thu mẫu cùng thời điểm, và trạng thái LED DC với 74HC08 được cấp nguồn.
- Liên kết ranh giới worker với yêu cầu thực thi và nghiệm thu CIRNET Lab-First.
