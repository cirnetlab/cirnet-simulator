# Security Policy — cirnet-simulator

Follow the [CIRNETLAB security policy](https://github.com/cirnetlab/.github/blob/main/SECURITY.md). Report vulnerabilities privately through Security → Advisories → Report a vulnerability when available. Otherwise request a private contact in a public issue without disclosing sensitive details. Identify affected revision, impact and safe reproduction. Never post secrets or personal data.

Maintained revisions are eligible for reports; no guaranteed support period or response SLA. Use authorized, isolated tests only. Review untrusted simulation inputs, resource bounds, numeric validation, worker isolation and artifact integrity. Simulation correctness does not demonstrate physical safety.

Review dependencies, workflow permissions and access controls before release. This policy is not a completed vulnerability audit.
